# Workshop Studio application icon

Generated artwork, extracted and converted into a transparent Windows icon.
Multi-resolution ICO: 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels.
The PNG is the sidebar/title-bar asset. The 512-pixel PNG is an enlarged export,
not an additional higher-resolution original. No promotional UI mockup is used in the application.
Workshop Studio is an independent community tool, not an official Valve product.
