# Kopierbare Demodateien

Diese Dateien erklären Formate für Workshop Studio 1.3.0. Sie sind kein vollständiges lauffähiges Mod-Projekt und enthalten keine Workshop-Ziel-ID. Kopiere benötigte Angaben bewusst in deine eigene ausgewählte Mod bzw. ihr zugehöriges Workshop-Projekt. Den Inhalt und das erwartete Verhalten erklärt das [Wiki](https://github.com/ZUMBYTE-AppSolution/WorkshopStudio/wiki/Beispiele).
