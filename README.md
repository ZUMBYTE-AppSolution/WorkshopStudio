# Workshop Studio

Windows-Werkzeug zum Verwalten eigener Project-Zomboid-Mods und Steam-Workshop-Inhalte. Lokale Mods lassen sich aus einem Stammordner einzeln erkennen, vorhandenen Workshop-Profilen zuordnen, prüfen und nach gezielter Bestätigung aktualisieren.

- [Deutsche Anleitung](README_DE.md)
- [Neueste Windows-Version](https://github.com/ZUMBYTE-AppSolution/WorkshopStudio/releases/latest)
- [Release-Prüfungen und offene Punkte](docs/DELIVERY_1.2.0.md)

Die Windows-Version wird bei einem `vMAJOR.MINOR.PATCH`-Tag auf einem Windows-Runner gebaut, getestet und als ZIP mit SHA-256-Prüfsummen veröffentlicht. Der integrierte Updater liest ausschließlich die offiziellen GitHub-Releases.
